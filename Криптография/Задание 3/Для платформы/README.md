# Задание 3

## Название задачи

> Кубическая угроза

## Описание

Один из наших инженеров решил внедрить асимметричное шифрование RSA для передачи коротких секретных токенов. Чтобы алгоритм работал максимально быстро на слабых устройствах, он выбрал наименьший возможный публичный экспонент — тройку.

Инженер уверяет, что длина ключа в 2048 бит делает систему абсолютно неприступной. Докажи ему, что без правильного дополнения данных (padding) математика может сыграть злую шутку.

## Флаг

`RCPISS{sm4ll_e_15_d4ng3r0u5_w1th0ut_p4dd1ng}`

| `output.txt` | Публичный ключ и перехваченный шифртекст. |
