## Описание задачи

Участникам предоставляется зашифрованное сообщение и конфигурационный файл, содержащий перемешанный алфавит из 64 символов. Необходимо догадаться, что перед ними кодировка Base64 с нестандартным (кастомным) алфавитом, выполнить обратную замену символов на стандартные и раскодировать сообщение, чтобы получить флаг.

---

## Решение

### Шаг 1: Анализ исходных данных

Изучаем предоставленные файлы. В файле `ciphertext.txt` находится строка, которая по своей структуре напоминает Base64 (включая знак заполнения `=` в конце), однако стандартные утилиты при попытке декодирования выдают мусор или ошибку.

Открываем `config.txt` и находим переменную `CUSTOM_CHARSET`, содержащую строку ровно из 64 уникальных символов. Это подтверждает гипотезу: разработчик реализовал алгоритм Base64, но заменил классический алфавит на свой собственный.

### Шаг 2: Обратная замена символов

Чтобы раскодировать сообщение, нужно вернуть зашифрованному тексту его изначальный вид. Для этого необходимо сопоставить символы из `CUSTOM_CHARSET` с символами стандартного алфавита Base64 в строгом порядке (`A-Z`, `a-z`, `0-9`, `+`, `/`) и произвести замену.

### Шаг 3: Написание скрипта

Пишем простой скрипт на Python для автоматизации процесса. С помощью функции `str.maketrans` создаем таблицу перевода из кастомного алфавита в стандартный, применяем ее к нашему шифртексту и используем библиотеку `base64` для финального декодирования:

```python
import base64
import string

# 1. Задаем стандартный алфавит Base64
STD_ALPHABET = string.ascii_uppercase + string.ascii_lowercase + string.digits + '+/'

# 2. Достаем кастомный алфавит из конфигурации
with open("config.txt", "r", encoding="utf-8") as f:
    for line in f:
        if line.startswith("CUSTOM_CHARSET="):
            custom_alphabet = line.strip()[15:]
            break

# 3. Читаем зашифрованный текст
with open("ciphertext.txt", "r", encoding="utf-8") as f:
    custom_b64 = f.read().strip()

# 4. Производим обратную замену символов
reverse_table = str.maketrans(custom_alphabet, STD_ALPHABET)
std_b64 = custom_b64.translate(reverse_table)

# 5. Раскодируем стандартный Base64
flag = base64.b64decode(std_b64).decode('utf-8')
print("Флаг:", flag)

```

Запуск скрипта выводит оригинальный текст и сам флаг.
