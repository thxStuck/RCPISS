# Задание 1

## Название задачи

> Неудачный Base64

## Описание

Наш стажер-разработчик решил, что стандартные алгоритмы кодирования — это слишком скучно и небезопасно. Он написал свой собственный крипто-модуль, взяв за основу Base64, но немного «улучшив» его для защиты от посторонних глаз. 

Нам удалось вытащить с сервера кусок конфигурационного файла и перехватить само секретное сообщение. Сможешь ли ты разобраться в логике стажера и обратить этот процесс?

## Флаг

`RCPISS{b4s364_w1th_cu5t0m_4lph4b3t_15_345y}`

## Файлы для участников

| Файл | Описание |
|------|----------|
| `ciphertext.txt` | Зашифрованное сообщение, перехваченное с сервера. |
| `config.txt` | Фрагмент конфигурационного файла с настройками кастомного кодировщика. |

> Поместите файлы задания в папку `files/`.
