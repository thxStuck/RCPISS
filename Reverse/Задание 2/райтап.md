# Райтап — Obfuscated Java

**Категория:** Reverse  
**Сложность:** easy
**Автор:** @alekseeee

---

## Описание задачи

Нашли какой-то Java-файл. Язык вроде знакомый, но ничего не понятно. Сможешь найти в нем флаг?

---

## Решение
1.  **Декомпиляция JAR-файла:**
    Для анализа содержимого `easy_java_reverse.jar` необходимо его декомпилировать. Существует несколько популярных инструментов для этого:
    *   **JD-GUI**: Графический декомпилятор, позволяющий удобно просматривать исходный код Java из JAR-файлов. Просто откройте `easy_java_reverse.jar` в JD-GUI.
    *   **Luyten**: Еще один популярный графический декомпилятор с хорошим функционалом.
    *   **CFR (CFR Decompiler)**: Консольный декомпилятор, который можно запустить командой `java -jar cfr.jar easy_java_reverse.jar > output.java`.
    *   **Fernflower (встроен в IntelliJ IDEA)**: Многие IDE, такие как IntelliJ IDEA, имеют встроенные декомпиляторы, которые автоматически показывают исходный код при открытии `.class` файлов внутри JAR.

    После декомпиляции вы получите исходный код Java.

2.  **Анализ класса `com.example.reverseapk.FlagFinder`:**
    В декомпилированном коде найдите класс `com.example.reverseapk.FlagFinder`.

3.  **Поиск пароля:**
    В этом классе обратите внимание на метод `checkPassword`. Он проверяет введенный пользователем пароль посимвольно. Анализируя условия, можно восстановить пароль: `s3cr3t_p@ss!`.

4.  **Извлечение флага:**
    Далее, изучите метод `getFlag`. Вы увидите, что флаг хранится в обфусцированном виде в массиве `ENCODED_FLAG` и дешифруется с помощью XOR-операции с ключом `42`.

    *   Массив байтов: `[120, 105, 122, 99, 121, 121, 81, 64, 75, 92, 75, 117, 72, 83, 94, 79, 73, 69, 78, 79, 117, 67, 89, 117, 76, 95, 68, 117, 94, 69, 117, 75, 68, 75, 70, 83, 80, 79, 87]`
    *   Ключ XOR: `42`

    Применив XOR-операцию к каждому элементу массива с ключом `42`, вы получите символы флага.

**Флаг:** `RCPISS{java_bytecode_is_fun_to_analyze}`
