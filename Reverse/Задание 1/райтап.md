## Описание задачи

Мы нашли этот странный файл на компьютере подозреваемого. Кажется, он требует какой-то пароль, чтобы выдать секрет. Сможешь его разгадать?

---

## Описание задания
Задание представляет собой Windows-исполняемый файл (.exe), который запрашивает пароль. При вводе верного пароля выводится флаг.

## Решение
1. Открываем файл в инструменте для статического анализа (например, `strings`).
2. Находим строку пароля: `super_secret_password_123`.
3. Используем ключ для получения флага

**Флаг:** `RCPISS{simple_strings_are_easy}`
