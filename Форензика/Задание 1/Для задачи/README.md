# Приказ ректора

**Категория:** DOCM Forensics / Malware Analysis
**Сложность:** Easy
**Формат флага:** `rcpiss{...}`

---

## Описание

Служба безопасности университета перехватила подозрительное электронное письмо, отправленное сотрудникам от имени ректората. К письму был приложен документ Microsoft Word с приказом об обязательном обновлении программного обеспечения.

Предварительный анализ показал, что документ содержит макросы. Ваша задача — провести криминалистический анализ вложенного файла, извлечь и деобфусцировать вредоносный код, определить индикаторы компрометации (IoC) и найти скрытый флаг.
