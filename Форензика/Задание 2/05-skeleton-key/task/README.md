# 05 — Скелетный ключ

**Категория:** Криминалистика учётных данных  
**Очки:** 175  
**Сложность:** Сложно

---

## Описание

Flask-приложение подписывает сессионные куки секретным ключом.  
Этот ключ не хранится в переменных окружения и не генерируется случайно — он вычисляется детерминированно из фиксированной строки прямо в исходном коде приложения.

Зная алгоритм и входную строку, любой может воспроизвести ключ и подделать сессионную куку с любыми правами.

Секретный ключ вычисляется следующим Python-выражением:

```python
import hashlib
hashlib.sha256(b'mindvault-rce-eval-search-filter').hexdigest()
```

Выполни это выражение в любом интерпретаторе Python 3 и submit результат.

---

## Формат флага

```
RCPISS{<64-символьная строка в нижнем регистре>}
```

**Пример оформления ответа:**

```
RCPISS{a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2}
```
