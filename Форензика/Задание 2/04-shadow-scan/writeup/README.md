# Разбор — 04 Теневое сканирование

## Где искать

```
live_response/network/proc_net_tcp.txt
```

## Почему именно этот файл

UAC читает `/proc/net/tcp` — это внутренняя таблица всех TCP-сокетов ядра.  
Строки со статусом `06` (TIME_WAIT) — это соединения, которые уже завершены, но ядро ещё хранит состояние. Они отражают недавнюю сетевую активность.

Во время атаки на сервер было отправлено ~165 000 HTTP-запросов со стороны атакующего. Тысячи из них перешли в состояние TIME_WAIT и видны в таблице.

## Как декодировать `5DB9D49B`

Ядро Linux хранит адреса в `/proc/net/tcp` как 32-битное целое в **little-endian**:

```
Hex-строка:           5D  B9  D4  9B
                      ↑              ↑
                  младший байт  старший байт

Разворот (big-endian): 9B  D4  B9  5D
Hex → Dec:            155 212 185  93
IPv4:                 155.212.185.93
```

Это IP-адрес MCP-сервера, с которого велось сканирование.

## Ответ

```
RCPISS{155.212.185.93}
```
