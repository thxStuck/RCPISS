# 04 — Теневое сканирование

**Категория:** Сетевая криминалистика  
**Очки:** 150  
**Сложность:** Сложно

---

## Описание

До начала эксплуатации атакующий провёл разведку — массовое сканирование веб-приложения.  
IP-адрес сканирующего хоста зафиксирован в таблице TCP-соединений ядра Linux.

В файле `live_response/network/proc_net_tcp.txt` присутствуют строки со статусом `06` (TIME_WAIT).  
В этих строках поле `rem_address` содержит значение `5DB9D49B:XXXX`.

Ядро Linux хранит IPv4-адреса в `/proc/net/tcp` в виде 32-битного целого числа в формате **little-endian hex**.

Декодируй значение `5DB9D49B` в стандартный IPv4-адрес (dotted-decimal) и submit его как флаг.

---

## Алгоритм декодирования

1. Раздели 8-символьную строку на 4 байта слева направо: `5D` `B9` `D4` `9B`
2. Переверни порядок байтов: `9B` `D4` `B9` `5D`
3. Переведи каждый байт из hex в десятичное число
4. Соедини через точку

---

## Формат флага

```
RCPISS{<IPv4-адрес>}
```

**Пример оформления ответа:**

```
RCPISS{10.20.30.40}
```
