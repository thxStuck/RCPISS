# 02 — Первый удар

**Категория:** Анализ временной шкалы  
**Очки:** 100  
**Сложность:** Средне

---

## Описание

Атакующий запустил интерактивный reverse shell с использованием Python-модуля `pty`.  
Когда Python импортирует модуль впервые, он компилирует его в `.pyc`-файл байткода.  
Время создания этого файла точно фиксирует момент первого использования модуля.

Скомпилированный файл модуля `pty` для Python 3.12 находится по пути:  
`/usr/local/lib/python3.12/__pycache__/pty.cpython-312.pyc`

Найди значение поля `mtime` для этого файла в архиве триажа.

---

## Формат флага

```
RCPISS{<Unix-timestamp, целое число>}
```

**Пример оформления ответа:**

```
RCPISS{1700000000}
```
