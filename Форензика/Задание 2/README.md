# EvalTrace 

Соревнование основано на реальном UAC-триаже, снятом с компрометированного Docker-контейнера.

---

## Сценарий

10 июня 2026 года SOC компании Nexion Labs зафиксировал аномальный исходящий трафик с контейнера `d68ac6f28555`.  
Контейнер запускал Flask-приложение **MindVault** — внутреннюю базу знаний для инженерных команд.  
Дежурный аналитик немедленно запустил UAC и снял полный триаж, не останавливая контейнер.

Тебе передан архив этого триажа. Никакого исходного кода, никакого PCAP, никакого бэйзлайна.  
Только то, что UAC успел собрать за 207 секунд.

---

## Архив

```
uac-d68ac6f28555-linux-20260610204058.tar.gz
```

> **Важно:** Windows не может распаковать архив — пути содержат символы `[` и `]`, недопустимые в NTFS.  
> Используй WSL, Linux-машину или виртуалку.

```bash
mkdir uac && tar -xzf uac-d68ac6f28555-linux-20260610204058.tar.gz -C uac
```
