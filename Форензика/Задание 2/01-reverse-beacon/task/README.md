# 01 — Обратный маяк

**Категория:** Анализ вредоносного ПО  
**Очки:** 50  
**Сложность:** Легко

---

## Описание

В момент снятия триажа внутри контейнера работал вредоносный процесс с PID 4184.  
Этот процесс устанавливал исходящее TCP-соединение с удалённым сервером под управлением атакующего.

Найди IP-адрес, к которому подключался процесс PID 4184.

---

## Формат флага

```
RCPISS{<IPv4-адрес>}
```

**Пример оформления ответа:**

```
RCPISS{1.2.3.4}
```
