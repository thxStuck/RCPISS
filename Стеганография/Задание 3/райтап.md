## Решение

### Шаг 1 - Разведка

Стандартный осмотр носителя:

```bash
strings prod_font.ttf | grep -iE 'RCPISS'   # пусто
exiftool prod_font.ttf
ttx -t name prod_font.ttf
```

Открытых строк с флагом нет. Таблица `name` выдаёт происхождение шрифта:

```
nameID=5  : Version 2.003W OFL
nameID=8  : ParaType Ltd
nameID=0  : Copyright © 2009 ParaType Ltd.
```

Это переименованный **PT Sans**. `unitsPerEm = 1000`.

### Ложные следы

* **`nameID=10` (Description):** *«Шрифт для служебного пользования… Автор:
  Pinfarina AG»* - просто строка с бесполезной для нас информацией.
* **base64** в метаданных ловит десятки «кандидатов»
  (`Software`, `Original`, `Modified`…) - слова из текста
  OFL-лицензии. Это тупик, который съел наше время(

Что-то тут не так, будет копать под сам шрифт.

### Шаг 2 - Энтропия LSB не работает

Пробуем найти глифы, у которых младшие биты координат распределены ~50/50. 

Прогон по всем глифам:
```
Среднее X_odd по всем глифам: 0.496
```

Ровно 50/50 **везде**. PT Sans от природы не привязан к чётной координатной
сетке, поэтому его LSB и без вмешательства высокоэнтропийны. Носители
полностью тонут в естественном шуме - энтропийный детектор бесполезен.

### Шаг 3 - Ищем расхождения с оригиналом

Раз донор - публичный OFL-шрифт, берём оригинальный PT Sans и сравниваем
координаты глиф-в-глиф. Расхождения = места вмешательства.

```bash
curl -sL -o PTSans.ttf \
  "https://github.com/google/fonts/raw/main/ofl/ptsans/PT_Sans-Web-Regular.ttf"
```

```python
from fontTools import ttLib
prod = ttLib.TTFont('prod_font.ttf')
orig = ttLib.TTFont('PTSans.ttf')
pg, og = prod['glyf'], orig['glyf']

for name in set(pg.keys()) & set(og.keys()):
    a, b = pg[name], og[name]
    if not (hasattr(a, 'coordinates') and hasattr(b, 'coordinates')):
        continue
    if len(a.coordinates) != len(b.coordinates):
        continue
    diffs = sum(1 for (ax, ay), (bx, by) in zip(a.coordinates, b.coordinates)
                if ax != bx or ay != by)
    if diffs:
        print(name, diffs, 'точек изменено')
```

Результат - ровно 4 глифа, максимальная дельта координаты равна `1`
(подтверждение LSB ±1 юнит):

| глиф | изменённых точек | всего точек |
|------|------------------|-------------|
| `a`  | 46               | 63          |
| `r`  | 15               | 17          |
| `k`  | 12               | 15          |
| `s`  | 5                | 42          |

Носители: **k, r, a, s** → «КРАС» (Краснодар).

### Шаг 4 - Кодирование

Анализ, по каким осям и точкам идут отличия:

```
k: ΔX=11 ΔY=8  | on=12 off=0   (у 'k' вообще нет off-curve точек)
r: ΔX=9  ΔY=12 | on=10 off=5
a: ΔX=30 ΔY=32 | on=15 off=31
s: ΔX=4  ΔY=4  | on=1  off=4
```

Изменены **обе оси (X и Y)** и **все типы точек** (у `k` 0 off-curve, но 12
изменённых on-curve → схема «все точки», а не «только off-curve»).

## Шаг 5 - Декодирование

Снимаем LSB обеих осей всех точек глифов в порядке `k → r → a → s`,
для каждой точки сначала X, затем Y. Первый собранный байт — длина.

```python
from fontTools import ttLib
tt = ttLib.TTFont('prod_font.ttf')
glyf = tt['glyf']

bits = []
for ch in 'kras':                      # порядок носителей: К-Р-А-С
    g = glyf[tt.getBestCmap()[ord(ch)]]
    for (x, y) in g.coordinates:        # все точки контура
        bits += [x & 1, y & 1]          # сначала X, потом Y

raw = bytes(int(''.join(map(str, bits[i:i+8])), 2)
            for i in range(0, len(bits) - 7, 8))
length = raw[0]                         # 1-байтовый префикс длины (0x18 = 24)
print(raw[1:1 + length].decode())
```
