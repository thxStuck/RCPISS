## Описание задачи

Я отправил работу на проверку преподавателю. Спустя время он ответил, что в работе есть что-то лишнее. 

Найди, то чего я не заметил во время отправки

---

## Решение

### Способ 1 - strings

```bash
strings Электротехника_лаб3.docx | grep RCPISS
```

Вывод:

```
RCPISS{curr3nt_1n_m3t4d4ta}
```

### Способ 2 - exiftool

```bash
exiftool Электротехника_лаб3.docx
```

В поле Keywords будет флаг.

### Способ 3 - вручную

```bash
unzip -p Электротехника_лаб3.docx docProps/core.xml
```

Находим тег:

```
xml<cp:keywords>RCPISS{curr3nt_1n_m3t4d4ta}</cp:keywords>
```

## Флаг

`RCPISS{curr3nt_1n_m3t4d4ta}`
