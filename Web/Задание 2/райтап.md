## Описание задачи

10 монет на счету. 3 ключа в магазине. 1 флаг на кону. Обычный покупатель купит один ключ и уйдет. Настоящий хакер найдет способ забрать всё и сразу.

---

## Решение

Вам предоставлен доступ к онлайн-магазину ключей. При регистрации каждый пользователь получает приветственный бонус в размере **10 монет**. 

В магазине продаются 3 разных ключа: **Key 1**, **Key 2** и **Key 3**. Каждый ключ стоит **10 монет**. 

Ваша задача — получить все три ключа, чтобы увидеть секретный флаг.

## Анализ уязвимости
При анализе исходного кода (или поведения приложения) можно заметить, что процесс покупки состоит из нескольких этапов:
1. Проверка текущего баланса пользователя.
2. Списание средств (обновление баланса).
3. Добавление товара в инвентарь.

Уязвимость типа **Race Condition** (состояние гонки) возникает, когда между проверкой баланса и его обновлением проходит время, в течение которого могут быть обработаны другие запросы. 

В файле `app.py` это выглядит так:
```python
user = db.execute('SELECT balance FROM users WHERE id = ?', (user_id,)).fetchone()

if user['balance'] >= price:
    time.sleep(0.5) # Искусственная задержка для облегчения эксплуатации
    new_balance = user['balance'] - price
    db.execute('UPDATE users SET balance = ? WHERE id = ?', (new_balance, user_id))
    db.execute('INSERT INTO inventory (user_id, item_name) VALUES (?, ?)', (user_id, item_name))
```

Поскольку `time.sleep(0.5)` дает нам окно в полсекунды, мы можем отправить три запроса практически одновременно. Все три запроса увидят, что баланс равен 10, пройдут проверку `if user['balance'] >= price`, и каждый из них вычтет 10 из начального баланса, в итоге баланс может стать отрицательным, но все три предмета будут куплены.

## Эксплуатация
Для эксплуатации необходимо отправить POST-запросы на `/buy/Key 1`, `/buy/Key 2` и `/buy/Key 3` одновременно.

### Шаги решения:
1. Зарегистрироваться и войти в аккаунт.
2. Использовать скрипт на Python с библиотекой `threading` или инструмент типа Burp Suite (Turbo Intruder).
3. Отправить 3 параллельных запроса.
4. Обновить главную страницу и забрать флаг.
