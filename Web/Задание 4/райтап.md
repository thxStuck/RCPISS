## Поиск уязвимости
Сервис использует Flask (Python). Есть подозрение на SSTI (Server-Side Template Injection), так как данные из куки могут обрабатываться шаблонизатором перед отправкой.

### Тестирование SSTI
1. Устанавливаем слушатель (например, используя [webhook.site](https://webhook.site) или `nc -lvp`).
2. Изменяем значение куки `webhook_config` на `{{7*7}}`.
3. Отправляем запрос на создание вебхука, указав свой URL.
4. В полученном POST-запросе в поле `data` видим `49`. Это подтверждает SSTI в Jinja2.

## Эксплуатация
Теперь нам нужно прочитать файл `flag.txt`. Используем стандартный payload для Jinja2 для чтения файлов.

Пример payload (URL-encoded при необходимости):
```jinja2
{{ self.__init__.__globals__.__builtins__.__import__('os').popen('cat flag.txt').read() }}
```

1. Устанавливаем этот payload в куку `webhook_config`.
2. Делаем запрос на создание вебхука.
3. Получаем флаг на свой сервер.

**Флаг:** `RCPISS{SST1_v14_C00k13_W3bh00k_Ev3nt}`
