# Задание 1

## Название задачи

> Open VPN — Перехват трафика

## Описание

Наша служба безопасности зафиксировала подозрительную активность внутри корпоративного VPN-сегмента. Внутренний агент регулярно передаёт конфиденциальные данные на удалённый узел. Передача идёт в открытом виде — никакого шифрования, никакой обфускации.

Вам выдан персональный доступ к корпоративному VPN. Подключитесь к сети, наблюдайте за трафиком и перехватите передаваемое сообщение.

**Портал для получения конфигурации:**

```
http://159.194.233.5:8080
```

1. Зайдите на портал и зарегистрируйтесь (любой никнейм).
2. Скачайте свой персональный `.ovpn` файл.
3. Подключитесь к VPN и слушайте сеть.

> Флаг передаётся автоматически с регулярным интервалом. Будьте терпеливы.
