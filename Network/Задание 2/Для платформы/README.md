## Название задачи : DeadEnd


> Задание 2

## Описание
Служба безопасности забила тревогу: в один из портов центрального коммутатора подключено неопознанное устройство. Физический линк горит зелёным, патч-корд на месте, а злоумышленник, судя по всему, уверен, что успешно закрепился в нашей сети и качает гигабайты конфиденциальных данных.
Сетевой инженер успел применить к этому порту базовые правила изоляции, превратив его в абсолютную пустышку. 
Разберись в конфигурации коммутатора и найди этот «холостой» порт. Его номер и станет твоим ключом.
